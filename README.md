# Анализ ассортимента интернет-магазина подарков методом ABC/XYZ

Аналитический проект по сегментации ассортимента британского интернет-магазина подарков на основе транзакционных данных. Цель — предложить обоснованные правила управления запасами и сформировать список SKU-кандидатов на вывод из ассортимента.

---

## Бизнес-задача

Компания хранит широкий ассортимент товарных позиций. Руководство считает, что часть SKU продаётся редко, занимает место на складе и усложняет закупки, но простое удаление «слабых» товаров может привести к потере выручки или ухудшению клиентского опыта.

**Главный вопрос:** какие товары нужно постоянно держать в ассортименте, какие требуют осторожного управления запасами, а какие можно рассматривать как кандидатов на сокращение — и каков потенциальный эффект?

**Ожидание бизнеса:** сокращение ассортимента примерно на 20% SKU.

---

## Данные

---

**Предобработка включала:**
- удаление строк с пропусками в описании, нулевой ценой и неизвестным покупателем;
- классификацию и обработку отменённых заказов (пометка `C` в номере счёта);
- удаление служебных операций (списания, ручные корректировки, доставка, тестовые записи);
- консолидацию строк с одинаковым товаром внутри заказа без удаления дубликатов;
- приведение дат к формату без времени;
- отбор данных за 12 полных месяцев.

Каждое решение по очистке зафиксировано и обосновано в ноутбуке.

## Подход

**1. ABC-анализ по выручке.** Товары ранжированы по вкладу в выручку и разделены на группы A (80% выручки), B (следующие 15%), C (оставшиеся 5%). Границы рассчитаны по накопительной доле.

**2. XYZ-анализ по вариативности спроса.** Для каждого SKU построен 12-месячный ряд количества проданных единиц с явным учётом нулевых месяцев. Рассчитан коэффициент вариации CV = std / mean. Границы: X = CV ≤ 0,5, Y = 0,5 < CV ≤ 1, Z = CV > 1.

**3. Углублённая обработка группы Z.** Внутри групп выделены:
- **новые товары** (450 SKU, первая продажа ≤ 6 месяцев назад);
- **молодые товары** (225 SKU, 6–12 месяцев с момента первой продажи);
- **сезонные товары** (280 SKU, подтверждено корреляцией Спирмена со сдвигом между двумя годами).

**4. Матрица ABC × XYZ.** Каждый товар получил одну из девяти комбинаций: AX, AY, AZ, BX, BY, BZ, CX, CY, CZ. Для каждой группы рассчитаны метрики: количество SKU, выручка, единицы, заказы, покупатели, средняя цена, активные месяцы.

**5. Формирование списка кандидатов на вывод.** Для группы CZ без меток построен совокупный рейтинг по пяти метрикам (выручка, заказы, единицы, покупатели, активные месяцы). Порог выбран через анализ чувствительности на пяти значениях: 15%, 17,5%, 20%, 22,5%, 25%.

**6. Оценка эффекта.** Сопоставлены доля сокращаемых SKU и доля исторической выручки, которую они формировали.

## Ключевые выводы

### 1. Выручка сильно сконцентрирована

**21,4% ассортимента (837 SKU) дают 80% выручки.** Распределение почти точно соответствует классическому правилу Парето 80/20 — это подтверждает, что магазин работает в типичной для ритейла модели.

### 2. Большая часть ассортимента имеет волатильный спрос

**62,4% товаров (2 441 SKU) — группа Z.** Это выше среднего по ритейлу, что объясняется спецификой магазина подарков: пики приходятся на праздники (Рождество, День матери, День отца).

### 3. Значительная часть «хаоса» — это новизна и сезонность

| Категория | SKU | Доля ассортимента |
|---|---|---|
| Новые товары (≤ 6 мес.) | 450 | 11,51% |
| Молодые (6–12 мес.) | 225 | 5,75% |
| Сезонные (подтверждено) | 280 | 7,16% |

**Высокий CV у этих товаров не означает непредсказуемый спрос** — он объясняется короткой историей или повторяющимися годовыми пиками. Такие SKU нельзя удалять автоматически.

### 4. Три самые критичные группы ABC × XYZ

| Группа | Выручка | Доля | Особенность |
|---|---|---|---|
| **AY** | 3 811 903 £ | **37,84%** | Лидеры с колеблющимся спросом |
| **AX** | 2 299 535 £ | **22,83%** | Ядро ассортимента, стабильные |
| **AZ** | 1 948 921 £ | **19,35%** | Высокая выручка, но хаотичный спрос |

**Группа AY — самая критичная.** Даёт больше трети выручки при колеблющемся спросе. Здесь максимальный риск как дефицита, так и затаривания.

### 5. Группа CZ — основной пул для проверки, но не список на удаление

1 680 SKU в группе CZ. Из них:
- **1 349** без меток — реальные кандидаты на проверку;
- **200** новых — недостаточно истории для решения;
- **94** сезонных — требуют особой стратегии закупки, а не вывода;
- **37** молодых — наблюдение до накопления истории.

### 6. Порог 20% — точка перегиба по данным

После этого значения наблюдается скачок средней стоимости добавленного при выборе порога товара и одновременное ускорение роста гипотетических будущих потерь.

### 7. Список кандидатов: 20% SKU приносят 0,42% выручки

| Метрика | Значение |
|---|---|
| Кандидатов на вывод | **782 SKU** |
| Доля ассортимента | **20,0%** |
| Их историческая выручка | 42 795 £ |
| Доля в общей выручке | **0,42%** |
| Средняя выручка кандидата | 55 £ |
| Средняя выручка по ассортименту | 2 575 £ |
| Отношение | **≈ 47×** |

**Ключевое соотношение проекта:** пятая часть ассортимента приносит менее половины процента выручки. Каждый кандидат в среднем в 47 раз слабее среднего товара магазина.

### 8. Историческая выручка не означает гарантированную потерю

Цифра **0,42%** — это факт за прошлый период, а не прогноз. Исторические данные не позволяют напрямую сказать, как поведут себя покупатели после изменения ассортимента. Часть спроса может перераспределиться на аналогичные товары. Реальную потерю выручки можно будет измерить только после вывода и сравнения с контрольным периодом.

## Предлагаемое решение

**Сократить 782 SKU (20% ассортимента)** из группы CZ без меток.

Список кандидатов сформирован по совокупному рейтингу, рассчитанному по пяти метрикам: выручка, количество заказов, количество проданных единиц, количество покупателей, количество активных месяцев. Для каждого товара в таблице есть **текстовая рекомендация** с конкретными основаниями: «мало заказов», «мало покупателей», «редкие продажи», «низкая выручка».

**Рекомендуется ручная проверка перед выводом:**
- товары без провальных метрик, но с низким общим рейтингом;
- товары с одним сильным показателем при низком общем рейтинге — возможны нишевые позиции.

## Оценка эффекта

| Показатель | Значение |
|---|---|
| Исходная выборка | 3 911 SKU |
| Предлагается вывести | 782 SKU (20,0%) |

## ⚠️ Ограничения исследования

Для принятия **операционного решения** об изменении ассортимента имеющихся данных недостаточно. Ниже — перечень сведений, которые нужно запросить у бизнеса.

- **Себестоимость и маржа по каждому SKU.** Анализ опирается на выручку, а не на прибыль. Некоторые «слабые» SKU могут быть убыточными (тогда вывод оправдан ещё сильнее), некоторые — высокомаржинальными при низкой выручке (тогда вывод несёт скрытую потерю).

- **Стоимость хранения.** Сколько стоит одна позиция на складе в месяц. Это ключевой параметр для решения о выводе «мёртвого груза».

- **Остатки на складе по каждому SKU.** Без этого нельзя понять, было ли количество товара достаточным для удовлетворения спроса.

- **История out-of-stock.** Периоды, когда товар был недоступен. Продажи не означают истинный спрос: если товара не было на складе, в транзакциях тоже будет ноль. Низкие продажи без данных о наличии нельзя трактовать как отсутствие интереса покупателей.

- **Срок годности и особые условия хранения** — для товаров соответствующей категории.

- **Объём упаковки товара и вместимость склада.** Позволит оценить соотношение полезности товара и занимаемого им места.

## Итог

Проект отвечает на бизнес-вопрос: **20% ассортимента приносит 0,42% выручки** — это «хвост», а не ядро. Из 3 911 SKU предложено 782 кандидата на вывод, исключены новые, молодые и сезонные товары. Решение обосновано анализом чувствительности, а список кандидатов пригоден для ручной проверки — для каждого товара указаны конкретные основания и метрики.
